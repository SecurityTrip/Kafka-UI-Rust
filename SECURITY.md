# Security Policy

## Supported versions

This project is currently in early development. Security fixes are provided on
the latest main branch.

## Reporting a vulnerability

Please do not open public issues for suspected vulnerabilities.

Instead, report privately to project maintainers with:

- Description of the issue
- Impact assessment
- Steps to reproduce
- Suggested remediation (optional)

Maintainers will acknowledge reports as quickly as possible and coordinate a
responsible fix and disclosure process.
