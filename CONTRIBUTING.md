# Contributing

Thank you for your interest in contributing.

## Ground rules

- Be respectful and constructive.
- Keep pull requests focused and small.
- Include tests or validation steps where relevant.
- Update documentation when behavior changes.

## Development setup

1. Install Rust (stable, 1.86+).
2. Clone the repository.
3. Run:

```bash
cargo fmt
cargo check
cargo run
```

## Commit guidance

- Use clear commit messages.
- Prefer one logical change per commit.
- Avoid mixing refactors and feature changes in one commit.

## Pull request checklist

- [ ] Code is formatted (`cargo fmt`)
- [ ] Project compiles (`cargo check`)
- [ ] Documentation updated (if needed)
- [ ] No unrelated file changes

## Reporting bugs

Please use the bug report template and include:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Logs or screenshots (if available)
- OS and Rust version

## Suggesting features

Please use the feature request template and explain:

- Problem statement
- Proposed solution
- Alternatives considered
